Ремни через колёса в обзоре (кадр c) — как собраны слои public/photos/tour-strap-*.webp.
Запуск по порядку в этой папке (python -I -X utf8):
  1. rim.py           — обод заднего колеса по краю закраины (эллипс) → rim.json
  2. geo.py           — шина = обод × 1,31; сопряжённые полудиаметры «вниз/назад» по
                        направлению платформы; ось колеса (смещение ступицы) → geo.json
     (затем в geo.json добавляются shape/box_* — рамка контура шины; готовые geo.json,
      rim.json, boxes.json лежат здесь же)
  3. strap_render.py  — лента 50 мм на середине протектора, крюки в 40 см, храповик;
                        за шиной скрыта, за кузовом — окно «рентгена» (без затемнения сайта; дыры
                        маски кузова заполнены, к крюку ремень темнеет плавно)
                        → strap-*.png → webp q95
     (заодно маски vis-*.npy — видимый ремень, full-*.npy — целиком)
  4. strap_edges.py   — обводка по геометрии: края ленты ровными дугами, торцы вокруг крюков; где лента
                        уходит за шину, линия открыта → edges.json (поле edge в strapImgs)
  5. comp.py          — просмотр поверх снимка
Готовые webp и параметры проявления (box, at, from, sweep) — в lib/tourParts.ts (strapImgs).
